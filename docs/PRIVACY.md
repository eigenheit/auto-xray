# AUTO Xray — данные и приватность

AUTO Xray не требует регистрации или отдельного аккаунта.

## Что хранится локально

Основные данные находятся в:

```text
~/Library/Application Support/AUTO Xray/
```

Там могут находиться:

- URL VLESS-подписки;
- HWID, используемый при запросе подписки;
- список разобранных узлов;
- сгенерированные Xray JSON-конфигурации;
- выбранный режим RF / EU / World / Manual;
- runtime state и предыдущие системные proxy-настройки;
- экспорт для V2RayXS.

Логи находятся в:

```text
~/Library/Logs/AUTO Xray/
```

## Какие внешние соединения выполняет AUTO Xray

AUTO Xray может обращаться к:

1. **вашей subscription URL** — при ручном обновлении подписки;
2. **proxy-узлам из вашей подписки** — через Xray-core во время работы;
3. **connectivity-check URL** — для проверки, что proxy действительно передает трафик и для автоматического восстановления соединения.

Публичная версия supervisor использует HTTP connectivity probes, чтобы не зависеть от старого LibreSSL в macOS Catalina. Это не меняет шифрование VLESS/Reality-туннеля между Xray и вашим proxy-сервером.

## Что не следует публиковать

Не размещайте в GitHub Issues, Discussions, скриншотах или логах без редактирования:

- subscription URL;
- UUID VLESS;
- Reality public/private keys и short IDs;
- HWID;
- логины, пароли, токены;
- приватные адреса сервисов.

Если отправляете лог для диагностики, сначала просмотрите его и удалите чувствительные значения.

## Удаление данных

В резервном ZIP-релизе находится `UNINSTALL_AUTO_XRAY.command`. Удаление может быть выполнено с сохранением пользовательских данных либо с их полной очисткой — следуйте подсказкам uninstall script.

Для технических деталей безопасности см. [SECURITY.md](../SECURITY.md).
