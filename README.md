# 🕊 AUTO Xray

Легкий VLESS/Reality-клиент для старых Intel Mac.

AUTO Xray создавался для компьютеров, на которых современные VPN/VLESS-клиенты уже не устанавливаются. Программа работает из строки меню macOS и автоматически выбирает доступный сервер из вашей VLESS-подписки.

> **Проверенная конфигурация:** Intel Mac (`x86_64`) + macOS Catalina 10.15.x.  
> Для Apple Silicon (M1/M2/M3/M4) этот релиз не предназначен.

## Скачать

Откройте раздел **Releases** справа на странице GitHub и скачайте последний релиз.

**`AUTO_Xray_Catalina_Intel_v2.5.dmg`**

## Быстрая установка через DMG

1. Скачайте `AUTO_Xray_Catalina_Intel_v2.5.dmg`.
2. Откройте файл.
3. Перетащите **AUTO Xray** в папку **Applications / Программы**.
4. Откройте **Applications / Программы** и запустите **AUTO Xray**.
5. В верхней строке меню появится голубь **🕊**.

Если macOS не разрешает открыть программу, это ожидаемо для версии без платной подписи Apple. Используйте инструкцию ниже: [Что делать с предупреждением macOS](#если-macos-не-разрешает-открыть-auto-xray).

## Первый запуск

Нажмите на **🕊** в строке меню:

1. Выберите **Обновить подписку**.
2. Вставьте HTTPS-ссылку вашей VLESS-подписки.
3. Выберите режим:
   - **Автовыбор · RF**
   - **Автовыбор · EU**
   - **Автовыбор · World**
   - или конкретный сервер через **Ручной выбор**.
4. Нажмите **Включить**.

Яркий голубь **🕊** — AUTO Xray включен.  
Полупрозрачный голубь — выключен.

AUTO Xray сам выбирает наиболее быстрый доступный узел внутри выбранной группы.

## Если macOS не разрешает открыть AUTO Xray

AUTO Xray пока распространяется без платной подписи **Apple Developer ID**, поэтому macOS Catalina может показать предупреждение о неизвестном разработчике.

### Вариант 1 — открыть через контекстное меню

1. Откройте **Applications / Программы**.
2. Найдите **AUTO Xray**.
3. Нажмите на приложение **правой кнопкой мыши** или `Control + клик`.
4. Выберите **Open / Открыть**.
5. В появившемся окне снова нажмите **Open / Открыть**.

Обычно это требуется только один раз.

### Вариант 2 — «Все равно открыть»

Если кнопки **Open / Открыть** нет:

1. Сначала один раз попробуйте запустить AUTO Xray обычным двойным нажатием.
2. Откройте:
   ** → System Preferences / Системные настройки → Security & Privacy / Защита и безопасность → General / Основные**.
3. Внизу окна должна появиться информация, что запуск AUTO Xray был заблокирован.
4. Нажмите **Open Anyway / Все равно открыть**.
5. Подтвердите запуск.

На более новых версиях macOS этот пункт находится в:

**System Settings → Privacy & Security → Security → Open Anyway**

Apple описывает этот способ как штатное ручное разрешение запуска приложения от неизвестного разработчика.

> Не отключайте Gatekeeper целиком и не используйте команды вроде `spctl --master-disable`. Для AUTO Xray это не требуется.

Если macOS пишет **«will damage your computer / повредит компьютер»**, не обходите это предупреждение. Удалите файл и скачайте релиз заново только с официальной страницы GitHub.

Подробно: [Установка и системные предупреждения](docs/INSTALLATION.md).

## Где хранятся данные

AUTO Xray не создает рабочие папки на Desktop.

Настройки, подписка и JSON:

```text
~/Library/Application Support/AUTO Xray/
```

Логи:

```text
~/Library/Logs/AUTO Xray/
```

При обновлении подписки программа сохраняет исходные и очищенные JSON-конфигурации, список дублей и резервный экспорт.

## Удаление

Если в релизе есть `UNINSTALL_AUTO_XRAY.command`, запустите его.

При удалении можно:

- удалить только приложение и сохранить подписку/настройки;
- либо удалить AUTO Xray полностью вместе с данными.

## Безопасность

Перед первым запуском:

- скачивайте релиз только из **GitHub Releases** этого репозитория;
- при наличии файла SHA-256 сравните контрольную сумму;
- не отключайте системную защиту macOS глобально;
- если система сообщает о вредоносном ПО или контрольная сумма не совпадает — не запускайте файл.

Подробнее: [SECURITY.md](SECURITY.md)

## Что внутри

AUTO Xray использует встроенный **Xray-core 1.8.4** для Intel macOS.

Проект не связан с Apple и не является официальным клиентом Xray.

Сведения о сторонних компонентах находятся в `THIRD_PARTY_NOTICES.txt`.
